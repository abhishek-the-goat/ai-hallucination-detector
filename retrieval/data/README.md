# Corpus Attribution

This corpus contains text extracted from Wikipedia articles using the
MediaWiki API. The text has been cleaned and split into passages.

Each record in corpus.json includes its source title and source URL.

Attribution-ShareAlike 4.0 International License (CC BY-SA 4.0),
subject to the terms applicable to the individual source material.
